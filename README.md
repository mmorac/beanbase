# Bean Base

This project was created with the vision of becoming the leading site to find the best specialty coffee around the globe.

### Technological stack

The project currently runs on React, and is hosted in Firebase for online display.

### Versioning

In order to update the version number displayed in the bottom right corner, the version number in the file package.json must be changed in every deployment. Consider using [Semantic Versioning](https://semver.org/) for naming each version.
